# خادم تعز إكسبرس

هذا خادم API أولي قابل للتطوير، وليس خدمة منشورة على الإنترنت. راجع `../README_AR.md` لخطوات التشغيل، إنشاء حساب المشرف، لوحة الويب، ونقاط API.

- PostgreSQL هو مصدر البيانات المركزي.
- JWT للمصادقة، وbcrypt لتجزئة كلمات المرور.
- أدوار النظام: `customer`, `courier`, `admin`.
- لا توجد حسابات للمطاعم.
- وسيلة الدفع الوحيدة حالياً `cash_on_delivery`.
- لا يوجد حقل مخزون؛ فقط `products.is_available`.
- رسوم المسافة حالياً مبنية على مسافة خط مستقيم، ويجب معايرتها وربطها بمسارات الطرق قبل الإطلاق.

لا تضع كلمات المرور أو `JWT_SECRET` أو بيانات قاعدة البيانات في مستودع عام. استخدم HTTPS ونسخاً احتياطية ومراقبة قبل التشغيل التجاري.
